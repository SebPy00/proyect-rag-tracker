# Project Screenshots

This directory is reserved for screenshots captured from the running application. No mock or generated screenshots are included.

Recommended captures:

1. The authenticated project list with representative projects.
2. A populated Kanban board with several columns and task cards.
3. The project board and RAG chat showing a question answered from visible task information.

Use data created specifically for the portfolio capture and avoid including credentials, tokens, personal information, or internal URLs.
